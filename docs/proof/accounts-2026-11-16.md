`shield()`** — the base Shield version from draft `3aaadf1` (already in main before the

implementation + Factory predate the Shield fix rounds `e7a4177` (F1–F9) and `3271231`
(factory rejects a bad cooldown up front). The Factory has no upgrade path (immutable
implementation, "No admin, no upgrade path"), so the fixes only go live via this fresh
deploy from main `3271231`. The 1.9 deployment is preserved as prior history in
`shared/deployments/testnet.json` under `accounts.previous`.
